# Smart Vacuum Robot Arduino

Arduino-based robot control code developed for my BSc final year project: Smart Vacuum Cleaner Bot with Solar PV.

## Project overview
This project focuses on controlling a smart vacuum cleaner robot using Arduino-based embedded control logic.

## Key features
- Robot movement control
- Obstacle/automation logic
- Arduino-based embedded system implementation
- Part of a renewable-energy-driven smart vacuum cleaner bot project

## Technologies used
- Arduino
- C/C++
- Embedded Systems
- Basic robotics control
